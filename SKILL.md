# kit-sites

Leia `00-COMECE-AQUI.md` nesta pasta e siga as fases. Os demais arquivos ficam ao lado:

- `FASE-1-ENTREVISTA.md` … `FASE-6-AJUSTES.md` — o processo, uma fase por arquivo
- `GUIA-DESIGN.md`, `GUIA-FRONTEND.md` — conhecimento de consulta (leia só a seção indicada)
- `base/` — starter copiado para `site/` na Fase 4
- `modelos/` — templates dos artefatos (BRIEFING, REFERENCIAS, ESPECIFICACAO, PUBLICACAO)
- `exemplos/` — um caso completo preenchido
- `README.md` — manual para a pessoa (não é para você)

Antes de qualquer coisa, descubra a fase atual pelos artefatos existentes (`00-COMECE-AQUI.md` §4).
